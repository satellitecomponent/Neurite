Neural API

    Function Calling Panel

    This is a terminal that allows you to execute Neurite's code from within Neurite itself.

    The Neural API allows one to sequence animations of function calls. The current features include:

    • Animate movements through the Mandelbrot set
    • Determine exact fractal coordinates to zoom to
    • Call a vision enabled Ai to determine the next movement.
    • Create notes
    • Prompt the Zettelkasten Ai
    • Prompt the user
    • Search and Zoom to Notes

    Use the "execute task..." text input to prompt the currently selected Ai. The Ai will write code using the Neural API to execute tasks in Neurite.

    This feature is a work in progress.
